# JusGBot

React + Vite MVP for jusgbot.fyi.

## Browser-first deployment
This project is designed so you do not need a local terminal to deploy it. Upload the project files to GitHub, then connect the repository to Cloudflare Pages.

## Build settings
- Framework preset: Vite
- Build command: npm run build
- Output directory: dist

## Next phase
